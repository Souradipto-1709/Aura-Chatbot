# 🤖 Aura — Your Personal AI Assistant

Aura is an interactive, voice-enabled AI chatbot built with Python, designed to make everyday tasks more engaging, useful, and fun. Combining AI-powered conversations, voice interaction, productivity tools, games, and digital resource libraries, Aura brings multiple features together in one personal assistant.

## ✨ Features

### 🧠 AI-Powered Conversations

- Powered by Google's Gemini AI for intelligent, natural-language conversations.
- Answers questions, explains concepts, and helps with everyday queries.
- Provides interactive responses beyond traditional rule-based chatbot conversations.

### 🎙️ Voice Interaction

- Voice output using text-to-speech technology.
- An energetic AI assistant experience with spoken responses.
- Speech-enabled prompts and responses for supported features.

### 🧮 Smart Calculator

- Addition, subtraction, multiplication, and division.
- Exponentiation and modulus operations.
- Average calculation and factorial.
- Interactive, menu-based calculations.

### 🌐 Website Library

- A dedicated collection of websites for quick access.
- Opens websites directly through the web browser.
- Makes accessing useful online resources easier.

### 📱 App Library

- A dedicated library of applications and app resources.
- Helps users access their selected apps and resources conveniently.

### 🎮 Interactive Games

- Fun, interactive experiences designed to make chatting with Aura more engaging.

### 🐢 Creative Tools

- Turtle graphics and creative drawing features.
- Visual experiments that combine programming and creativity.

### 😂 Entertainment

- Joke generation for a more playful chatbot experience.
- Friendly interactions alongside useful assistant features.

### 🛠️ Built with Python

- Modular functions for organizing different features.
- Browser integration for opening websites.
- Interactive terminal-based conversations.
- Expandable architecture for adding more features over time.

## 🚀 Project Goal

Aura aims to bring artificial intelligence, voice interaction, productivity, entertainment, and creativity into one accessible personal assistant. It is an evolving project built to explore Python programming, AI integration, and real-world software development.

## 💻 Technologies Used

- Python
- Google Gemini API
- Text-to-speech technology
- Python web browser integration
- Turtle graphics
- Python libraries and modules

## 🔮 Future Possibilities

Aura is a continuously evolving project, with opportunities to introduce more AI capabilities, interactive games, smarter tools, and additional integrations.

## 👨‍💻 About the Project

Aura is a personal AI assistant project developed to explore the possibilities of Python, artificial intelligence, and interactive software.
